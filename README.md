## Оценивание
[Ссылка на таблицу с оценками](https://docs.google.com/spreadsheets/d/1qquDIWuKwUlShvKw1fzyfPiXMCfK8jtfnG69OnuYltw/edit?usp=sharing)

**Формула оценки**: 0,25*ДЗ + 0,25*квизы + 0,25*КР + 0,25*проект

1. ДЗ — выдается раз в 2-3 недели
2. Тесты — в начале каждого занятия небольшой тест на 10 минут на тему предыдущего занятия. 
3. Контрольные — по ходу курса будут две контрольные - по линейным моделям и по деревьям (констатирующие)
4. Проект — в конце курса нужно будет защитить проект - самостоятельно выбрать датасет и поэкспериментировать с предсказанием таргета (творческая)

Оценки выставляются по 10-балльной шкале как в ВШЭ ([подробности](https://www.hse.ru/studyspravka/Scale?ysclid=m1ngfy59pb473469014)), потом переводятся в 5-балльную

В аттестат идет средняя оценка за 3 семестра. При наличии конспектов по темам КР1 и КР2 за эти контрольные выставляется +1 балл.
